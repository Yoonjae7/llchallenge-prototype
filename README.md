# 멋쟁이 챌린지 · 프로토타입

"클로드 배워서 인생 바꾸기" (60일 챌린지) 데모. **메인 페이지**와 **Course Overview** 두 화면으로 구성됩니다.

## 여는 법

### 1) 가장 간단 — 더블클릭
`index.html` 을 브라우저로 열면 바로 실행됩니다.
(React·Tailwind 를 CDN 으로 불러오므로 **인터넷 연결**이 필요합니다.)

### 2) 로컬 서버로 열기 (권장)
일부 브라우저는 `file://` 에서 클립보드 복사 등을 제한합니다. 아래처럼 간단한 서버로 열면 모든 기능이 동작합니다.

- **Node 가 있으면**
  ```bash
  npx serve .
  ```
- **Node 가 없으면 (Windows PowerShell)** — 포함된 스크립트 사용
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\serve.ps1
  ```
  이후 브라우저에서 `http://localhost:8123/` 접속. (`serve.ps1` 은 이 폴더에서 실행)

> `serve.ps1` 이 없다면 원하는 정적 서버 아무거나 사용해도 됩니다.

## 화면

- **메인** (`#/`) — 히어로 · X/O 관점 전환 · 60일 큰 숫자 · Day 유닛 흐름 · 분할 화면 설명 · 커리큘럼 티저 · 자가진단 · 최종 CTA. "지금 시작하기" → Day 1로 진입.
- **여정 / 학습 홈** (`#/learn`) — **듀오링고형 경로**. 커리큘럼은 숨겨져 있고 오늘 것만 보여줍니다. 완료한 날은 ✓, 오늘은 하이라이트, 다음 날은 🔒. 상단에 스트릭 🔥 · 진행률 · 환급 바.
- **Day 화면** (`#/day/N`) — 그날 미션 · 오늘의 결과물(복붙 템플릿) · 완료 인증. 완료하면 **내일 미리보기** 티저 공개.
  - **Day 1은 동기부여 전용** — "AI로 뭘 하지? → 이 일을 어떻게 맡기지?" 관점 전환 + "오늘, 이 세 가지만" 3카드.
- **규칙** (`#/rules`) — 매일 자동 해금 · 오늘 것만 공개 · 밤 11:59 시작해도 인정 · 몰아서 금지 · 시작일 한 번만 선택.
- **환급** (`#/refund`) — 20만원 → 10만원. 모든 미션 완료 조건 · 몰아서 불인정 · **스트릭 끊기면 진행 바가 사라짐**(자격 마감 UI).

### 🧪 데모 컨트롤 (우하단)
학습 화면 우하단의 🧪 버튼을 열면, 실제 서비스에서 자동으로 흐르는 시간을 **직접 조작**해 데모할 수 있습니다.
- **시작일** 직접 지정 · **오늘 = Day N** 을 ± 로 이동
- **오늘 미션 완료 / 스트릭 끊김** 토글 (환급 바 사라짐 시연)
- 바로가기: `Day 1`(동기부여) · `Day 12`(완주 중) · `완주(60)` · 여정 · 규칙 · 환급 · 초기화

## 구조 (실제 서비스 이식용)

| 파일 | 역할 |
|---|---|
| `index.html` | React 컴포넌트 + 해시 라우팅 + 공유 상태(AppProvider) + 디자인 시스템(Tailwind config) |
| `data.js` | 데이터 모델 (`window.MJC_DATA`) — 상품 · 주차/Day · Day 1 동기부여 · 규칙 · 환급 · 유닛 10영역 |

데이터와 화면이 분리돼 있어, 실제 프로젝트(Vite/Next 등)로 옮길 때 `data.js` 모델과 컴포넌트 JSX 를 그대로 재사용할 수 있습니다.
Day 진행 상태는 **시작일 기준으로 시간이 자동 계산**(듀오링고형)되며, 데모에서만 🧪 컨트롤로 덮어씁니다. 상태는 브라우저 `localStorage` 에 저장돼 새로고침해도 유지됩니다(첫 방문은 항상 Day 1).
